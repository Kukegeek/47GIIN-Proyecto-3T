# Declaración de Uso de Inteligencia Artificial — Sprint 0

Durante el desarrollo de este Sprint 0, la Inteligencia Artificial se ha utilizado como herramienta de apoyo para agilizar tareas mecánicas de desarrollo, bajo la supervisión directa del autor.

### Aportación del autor
* Diseño conceptual y boceto inicial del modelo entidad-relación con las 15 tablas en 3FN.
* Definición de la arquitectura técnica: enfoque Local-First, módulos nativos Vanilla JS, sin frameworks y con SQLite.
* Especificación de las reglas de negocio, integridad referencial y borrados en cascada.

### Tareas asistidas con IA
* A partir del boceto y las directrices de estructura facilitadas por el autor, la IA ayudó a redactar la sintaxis del script DDL (sql/schema.sql).
* Creación de la plantilla base del repositorio, configuración del entorno (package.json, workflow CI de GitHub Actions).
* Apoyo en la codificación del test de humo (tests/db/schema.test.js) para validar automáticamente la integridad de las tablas.

Todo el material resultante ha sido revisado, ajustado y verificado por el autor en local para garantizar el cumplimiento de los requisitos del proyecto.
